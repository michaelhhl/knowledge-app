# 数据与隐私

## 数据分类

| 数据 | 存放 | 是否进 git |
|------|------|------------|
| 知识 Markdown | `knowledge/` | 是（注意不要写入秘密） |
| 产品规格 | `docs/` | 是 |
| API 密钥 | `.env` / 系统环境 | 否 |
| 向量/关键词索引 | `.local/` 或配置的 `INDEX_DIR` | 否 |
| 会话记录 | 默认仅内存；P1 可本地文件 | 否（默认） |
| 有用/无用反馈 | 本地 | 否 |

## 发送到 LLM 提供商的内容

仅允许：系统规则、改写后的查询、检索到的 chunk 文本、必要的短对话历史。

不允许：`.env`、本机其他目录、用户未粘贴进输入框的文件。

## 保留与删除

- 第一版重启后会话可丢失。
- 用户应能「新会话」立即丢弃当前内存历史。

## 威胁意识（实现时对照）

- 知识文件中的提示词注入：系统规则优先级更高。
- 路径穿越：知识浏览与引用不得读出 `knowledge/` 之外。
- 密钥进日志、进前端包：禁止。
